# Q4 — Daily Conviction Markets

A React + Vite + Tailwind CSS v4 rebuild of the Q4 dashboard UI (Dashboard, Questions, Question Detail, My Convictions, How Q4 Works).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build for production

```bash
npm run build
```

Output goes to `dist/`.

## Notes

- Platform name stays **Q4**; the in-app currency unit has been renamed to **Quai** (e.g. "85.40 Quai").
- Icons: lucide-react
- Fonts: Inter (body) + Manrope (display/headings), loaded from Google Fonts.
